# Developer documentation

Written and maintained by the teams (see [AGENTS.md](../AGENTS.md)).

- `contracts/`: interfaces between teams. Changing one needs approval from
  every dependent team lead.
- `decisions/`: one short file per decision: context, decision, consequences.
  Name files `NNNN-short-title.md`.
- `resources.md`: infrastructure and resources available to the teams.

Each team may add its own folder, for example `dev-docs/daemon/`.
